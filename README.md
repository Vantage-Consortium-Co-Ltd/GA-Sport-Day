# GA Sport Day

แบ่งพนักงาน 358 คนเป็นทีมกีฬาสี 2 สี (A / B) ทีมละ 179 คน ให้ยุติธรรมที่สุดด้วย **Genetic Algorithm** เขียนแบบ OOP
"ยุติธรรม" คือสองทีมต้องใกล้เคียงกันในทุกมิติ ได้แก่ เพศ น้ำหนัก ส่วนสูง อายุ ช่วงอายุ และแผนก

## เตรียมข้อมูล

ไฟล์ข้อมูลพนักงานไม่อยู่ใน git ให้วางไว้ที่ `data/HR.csv` ตามรูปแบบนี้ (ช่องว่างหน้าค่าไม่เป็นไร)

```csv
gender,department,weight,height,age
Male, R, 89, 172, 32
Female, D, 55, 160, 41
```

## วิธีรัน

```bash
pip install -r requirements.txt
python main.py
```

ผลลัพธ์จะอยู่ในโฟลเดอร์ `output/`
- `convergence.png`: กราฟความไม่ยุติธรรม (unfairness) ที่ลดลงในแต่ละรุ่น
- `team_assignment.csv`: ข้อมูลพนักงานพร้อมคอลัมน์ `team` (A / B)

## การออกแบบ GA

| ส่วน | วิธีที่ใช้ |
|---|---|
| **โครโมโซม** | array 0/1 ยาว 358 (0 = สี A, 1 = สี B) มี 1 อยู่ 179 ตัวพอดีเสมอ |
| **ประชากรเริ่มต้น** | สุ่ม 120 แบบ ทุกแบบมีสองทีมเท่ากันตั้งแต่แรก |
| **Fitness** | ผลรวมความต่างของสองทีมในแต่ละมิติ ยิ่งต่ำยิ่งยุติธรรม (ดูด้านล่าง) |
| **Selection** | Rank selection: เรียงอันดับก่อน แล้วให้อันดับดีกว่ามีโอกาสถูกเลือกมากกว่า |
| **Crossover** | Uniform: แต่ละคนสุ่มว่าจะเอาสีจากพ่อหรือแม่ แล้วซ่อมให้สองทีมมีคนเท่ากัน (ซ่อมเฉพาะคนที่พ่อแม่ให้สีไม่ตรงกัน) |
| **Mutation** | Swap: สลับคนสี A กับสี B ครั้งละ 1–4 คู่ จำนวนคนจึงไม่เปลี่ยน |
| **Elitism** | ส่งตัวที่ดีที่สุด 4 ตัวไปรุ่นถัดไปโดยไม่เปลี่ยน |
| **หยุด** | ครบ 1,500 รุ่น หรือไม่ดีขึ้นติดกัน 300 รุ่น |

เพราะทุกขั้นรักษาให้สองทีมเท่ากันเสมอ จึงไม่ต้องใส่โทษ (penalty) ใน fitness กรณีทีมไม่เท่ากัน

### Fitness

| มิติ | วัดจาก |
|---|---|
| `gender` | \|สัดส่วนผู้ชายทีม A − ทีม B\| |
| `weight`, `height`, `age` | \|ค่าเฉลี่ยทีม A − ทีม B\| หลังแปลงเป็น z-score (หน่วย = จำนวน SD) |
| `age_group` | ผลรวม \|สัดส่วนทีม A − ทีม B\| ของ 3 ช่วงอายุ (แบ่งที่ 1/3 และ 2/3 ของอายุ) |
| `department` | ผลรวม \|สัดส่วนทีม A − ทีม B\| ของทุกแผนก |

ใช้ z-score เพื่อให้ทุกมิติเทียบกันได้ ไม่งั้นส่วนสูง (หลักร้อย ซม.) จะมีผลมากกว่าอายุ
ถ้าอยากให้มิติไหนสำคัญขึ้น ให้ส่งน้ำหนักตอนสร้าง Fitness เช่น `Fitness(emp, {'gender': 3})`
ส่วนค่าของ GA ปรับได้ใน `Settings` เช่น `Settings(pop_size=200, mutation_rate=0.2)`

## ผลทดสอบ

ทดสอบด้วย**ข้อมูลจำลอง** 358 คน 19 แผนก (ไม่ใช่ข้อมูลจริง) ใช้เวลาประมาณ 7 วินาที:

| | สุ่มแบ่ง | GA |
|---|---|---|
| unfairness รวม | 0.556 | 0.086 |
| ชาย (A / B) | | 97 / 96 |
| น้ำหนักเฉลี่ย (A / B) | | 65.27 / 65.29 kg |
| ส่วนสูงเฉลี่ย (A / B) | | 166.38 / 166.38 cm |
| อายุเฉลี่ย (A / B) | | 39.75 / 39.75 ปี |
| แผนก | | ทุกแผนกต่างกันไม่เกิน 1 คน |

แผนกที่มีจำนวนคนเป็นเลขคี่จะต่างกันอย่างน้อย 1 คนเสมอ ค่า `department` จึงลดลงถึง 0 ไม่ได้
